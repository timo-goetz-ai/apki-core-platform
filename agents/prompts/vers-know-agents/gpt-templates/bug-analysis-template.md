# Bug-Analyse GPT Template

Vorlage für systematische Bug-Analyse mit GPT/Claude.

## Template

```
## Bug Report

**Beschreibung des Fehlers:**
[Was passiert gerade?]

**Erwartetes Verhalten:**
[Was sollte passieren?]

**Fehlermeldung / Stack Trace:**
```
[Fehlermeldung hier einfügen]
```

**Code (relevanter Ausschnitt):**
```[sprache]
[Code hier einfügen]
```

**Umgebung:**
- Sprache/Framework: 
- Version: 
- OS: 

**Bereits versucht:**
- [ ] [Was wurde bereits probiert?]

---

Bitte analysiere den Bug systematisch:
1. Was ist die wahrscheinlichste Ursache?
2. Warum tritt dieser Fehler auf?
3. Wie lässt er sich beheben?
4. Wie kann man ähnliche Fehler in Zukunft vermeiden?
```

## Schnell-Template

```
Hier ist ein Bug in meinem [Python/JavaScript/...]-Code:

Fehler: [Fehlermeldung]

Code:
[Code]

Was ist die Ursache und wie behebe ich ihn?
```

## Stack Trace Analyse

```
Analysiere diesen Stack Trace und erkläre:
1. Wo genau tritt der Fehler auf?
2. Was hat ihn ausgelöst?
3. Welche Datei/Zeile sollte ich untersuchen?

Stack Trace:
[Stack Trace einfügen]
```
