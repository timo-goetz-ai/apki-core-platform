# Genehmigungsrichtlinie

**Geltungsbereich:** FinanceAgent, alle Agenten mit Ausgabenbefugnis  
**Zweck:** Definiert Freigabegrenzen für automatisierte Transaktionen.

## Finanzielle Freigabegrenzen

| Betrag | Freigabe durch | Methode |
|---|---|---|
| ≤ 500 € | FinanceAgent (automatisch) | Automatische Buchung |
| 501 – 5.000 € | Abteilungsleiter | E-Mail-Bestätigung oder App-Genehmigung |
| 5.001 – 50.000 € | Geschäftsführung | Digitale Unterschrift |
| > 50.000 € | Vorstand + externe Prüfung | Physische Unterschrift |

## Prozess-Freigaben

| Prozess | Freigabeschwelle | Eskaliert an |
|---|---|---|
| Einstellung neuer Mitarbeiter | Immer | HR-Leitung + GF |
| Neuer Lieferantenvertrag | > 10.000 € / Jahr | Einkauf + GF |
| IT-Systemänderung (produktiv) | Immer | IT-Leitung |
| Datenfreigabe nach außen | Immer | Datenschutzbeauftragter |

## Audit-Trail

Jede Genehmigung oder Ablehnung wird mit Zeitstempel, Entscheider und Begründung im Audit-Log erfasst.
