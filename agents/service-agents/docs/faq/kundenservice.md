# FAQ: Kundenservice

**Ziel-Agent:** CustomerServiceAgent  
**Aktualisiert:** automatisch

---

## Wie lange dauert die Bearbeitung meiner Anfrage?

Einfache Anfragen werden innerhalb von 2 Minuten automatisch beantwortet. Komplexere Anfragen werden innerhalb von 4 Stunden durch unser Team bearbeitet.

## Wie kann ich den Status meiner Bestellung prüfen?

Geben Sie Ihre Bestellnummer an – der Agent ruft den aktuellen Status direkt aus dem System ab.

## Was tue ich, wenn mein Problem nicht gelöst wurde?

Antworten Sie auf unsere Follow-up-E-Mail oder schreiben Sie erneut. Bei wiederholten Kontakten zum selben Problem wird automatisch ein Mensch eingeschaltet.

## In welchen Sprachen wird Support angeboten?

Deutsch, Englisch und Französisch werden vollständig automatisiert unterstützt. Weitere Sprachen werden an spezialisierte Mitarbeiter weitergeleitet.

## Wie gebe ich Feedback zur Servicequalität?

Nach jeder Anfrage erhalten Sie eine kurze Bewertungsanfrage (1–5 Sterne). Ihr Feedback fließt direkt in die Verbesserung des Systems ein.
