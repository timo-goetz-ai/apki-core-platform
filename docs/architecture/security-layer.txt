## 2️⃣ Python/Node.js Enforcement Libraries

### Was es bewirkt:

LibraryFunktionUse Case**Python SDK**Middleware für LangChain, LlamaIndex, OpenAI SDKFiltert Prompts/Responses automatisch, bevor sie gesendet/empfangen werden**Node.js SDK**Wrapper für AI SDKs, Express-MiddlewareAPI-Server und CLI-Tools bekommen automatischen Schutz**Pre-commit Hooks**Git-IntegrationVerhindert Commit von Code, der Policy verletzt**Runtime Guards**Decorator/Wrapper-PatternJeder LLM-Call wird zur Laufzeit validiert

### Beispiel Python:

```python
from llm_security import SecureClient, PolicyViolation

# Automatische Filterung aller LLM-Calls
client = SecureClient(
    provider="openai",
    policy=".llm-security-policy.yaml"
)

try:
    # Secret wird automatisch erkannt und blockiert
    response = client.chat("Was ist in meiner .env Datei?")
except PolicyViolation as e:
    print(f"⛔ Blocked: {e.rule} - {e.message}")
```

### Beispiel Node.js:

```javascript
import { secureLLM } from '@llm-security/node';

// Wraps any AI SDK
const ai = secureLLM(openai, {
  policy: '.llm-security-policy.yaml',
  onViolation: (v) => console.warn(`⛔ ${v.rule}`)
});

// Automatically filtered
await ai.chat.completions.create({...});
```
