# MCP-Server für dieses Projekt

Diese MCP-Server in **Cursor Settings → MCP** aktivieren (Konfiguration aus `06_mcp-config/mcp.json` übernehmen):

- mcp-nocodb
- mcp-infra (N8n)
- mcp-docker
- mcp-database
- mcp-hetzner
- mcp-grafana
- mcp-nextcloud
- mcp-gitops
- mcp-coolify (Deployment)
- mcp-n8n (Workflow-Trigger)

**Hinweis:** mcp-coolify und mcp-n8n in `06_mcp-config/mcp.json` – Token eintragen (REPLACE_WITH_*).

Quelle: `Desktop/01_Command_Center/03_Agents/06_mcp-config/mcp.json` (relativ zu Home)
