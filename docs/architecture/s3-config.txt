## TECHNISCHE UMSETZUNG

### API-Integration
```yaml
datenquellen:
  hetzner_s3:
    type: "REST API"
    endpoint: "https://api.hetzner.cloud/v1/object_storage"
    authentication: "Bearer Token (aus .env)"
    refresh_interval: "5 minutes"
    
  backup_monitor:
    type: "NocoDB Table"
    table: "s3_backups"
    fields:
      - backup_date
      - backup_size
      - backup_status
      - integrity_check
      - next_scheduled
    refresh: "Real-time"
```

### NocoDB Tabelle erstellen (falls nicht existent):
```sql
CREATE TABLE s3_backups (
  id INTEGER PRIMARY KEY AUTO_INCREMENT,
  backup_date DATETIME NOT NULL,
  backup_size_gb DECIMAL(10,2),
  backup_status VARCHAR(50),
  integrity_verified BOOLEAN,
  next_scheduled DATETIME,
  backup_notes TEXT,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP
)
```

### Grafana Panel (Alternative)
Falls du Grafana nutzt, erstelle 3 Panels:
1. **Stat Panel**: Storage Usage %
2. **Gauge Panel**: Available Storage
3. **Table Panel**: Backup History + Scheduled
